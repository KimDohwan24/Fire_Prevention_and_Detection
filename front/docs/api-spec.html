1. 공통 규칙

Base URL

http://localhost:5000/api

표기 규칙

  • 모든 JSON 키는 snake_case (DB 컬럼명과 동일)
  • 모든 날짜/시간은 ISO 8601 문자열: "2026-08-08T14:30:00"
  • 신뢰도(confidence)는 0~1 사이 소수: 0.9123
  • 좌표(lat/lng)는 소수: 37.5665, 126.9780

인증

로그인 시 발급되는 JWT를 모든 요청 헤더에 포함한다. (🔒 표시된 API)

Authorization: Bearer <access_token>

공통 에러 형식

모든 에러 응답은 아래 형태로 통일한다.

{
  "code": "INVALID_CREDENTIALS",
  "message": "아이디 또는 비밀번호가 일치하지 않습니다."
}
상태코드의미
400요청 형식 오류 (필수 필드 누락, 타입 오류)
401미인증 (토큰 없음/만료)
403권한 없음 (VIEWER가 ADMIN 기능 호출 등)
404리소스 없음
500서버 내부 오류

페이징 공통 형식

목록 API는 ?page=1&size=20 쿼리를 받고, 아래 형태로 응답한다. (page는 1부터 시작)

{
  "items": [ ... ],
  "page": 1,
  "size": 20,
  "total_count": 42,
  "total_pages": 3
}

상태값 (Enum) 정리

필드값
user_roleADMIN(관리자) · VIEWER(조회전용)
user_statusACTIVE(정상) · SUSPENDED(정지) · WITHDRAWN(탈퇴)
cctv_statusACTIVE(정상) · INACTIVE(중지) · ERROR(오류)
event_statusCONFIRMED(확정) · DISMISSED(기준미달)
event_classFLAME(불꽃) · SMOKE(연기) · FLAME_SMOKE(둘다)
media_typeFRAME(프레임 이미지) — CLIP(영상 클립)은 2026-08-10 폐기, 프레임만 저장한다
alert_level1(1차 알림) · 2(승격) · 3(최종)
alert_channelPUSH(앱알림) · SMS(문자)
alert_statusSENT(발송) · READ(확인) · CANCELED(취소) · NO_RESPONSE(무응답)
report_statusSENDING(전송중) · ACCEPTED(접수확인) · NO_RESPONSE(무응답으로 승계) · FAILED(전송실패)

관리자 로그인. 성공 시 JWT 발급.
Request Body
필드타입필수설명
user_idstringO로그인 아이디
user_pwstringO비밀번호 (평문, HTTPS 전제)
Response 200
{
  "access_token": "eyJhbGciOiJIUzI1NiIs...",

    "user_no": 1,

Query Parameters
파라미터타입필수설명

  "items": [
    {
      "user_no": 1,

  "page": 1, "size": 20, "total_count": 3, "total_pages": 1

POST /api/users 🔒 ADMIN
사용자 등록.
Request Body
필드타입필수설명
user_idstringO로그인 아이디 (중복 불가)
user_pwstringO비밀번호
user_namestringO이름
user_emailstringX이메일
user_phonestringX휴대전화 (SMS 알림 수신 번호)

user_genderstringX성별
user_addressstringX주소
Response 201
{ "user_no": 4 }
Errors
상태코드code설명
409DUPLICATE_USER_ID이미 사용 중인 아이디
PUT /api/users/<user_no> 🔒 ADMIN (본인은 일부 수정 가능)
사용자 정보 수정. 보낸 필드만 갱신한다. user_pw 포함 시 비밀번호 변경. 탈퇴 처리도 이 API로 한다: user_status=WITHDRAWN을 보내면 서버가 user_withdrawal_at을 함께 기록한다.
Request Body (모두 선택)
{
  "user_name": "홍길동",
  "user_email": "new@fireguard.kr",
  "user_phone": "010-9999-8888",
  "user_role": "VIEWER",
  "user_status": "SUSPENDED",
  "user_pw": "newPassword!"
}
Response 200
{ "user_no": 4 }

6. 관리자 알림 (Alerts)

GET /api/alerts 🔒 인증 필요
내 알림 목록 (로그인한 사용자 기준). 최신순, 페이징 공통 형식.
Query Parameters
파라미터타입필수설명
alert_statusstringXSENT 등으로 필터
page / sizenumberX기본 1 / 20
Response 200
{
  "items": [
    {
      "alert_no": 5,
      "event_no": 12,
      "event_class": "FLAME",
      "cctv_name": "정문 카메라",
      "alert_level": 1,
      "alert_channel": "PUSH",
      "alert_status": "SENT",
      "alert_sent_at": "2026-08-08T14:30:05",
      "alert_deadline_at": "2026-08-08T14:33:05",
      "alert_responded_at": null
    }
  ],
  "page": 1, "size": 20, "total_count": 8, "total_pages": 1
}
POST /api/alerts/<alert_no>/respond 🔒 인증 필요 (본인 알림만)
알림에 응답한다. 유예 마감(alert_deadline_at) 안에 CANCEL하면 119 신고를 중단한다.
Request Body
필드타입필수설명
actionstringOREAD(화재 확인) | CANCEL(오탐 취소)
Response 200
{
  "alert_no": 5,
  "alert_status": "READ",
  "alert_responded_at": "2026-08-08T14:31:00"
}
Errors
상태코드code설명
403NOT_YOUR_ALERT다른 사용자의 알림
409DEADLINE_PASSED유예 마감 이후의 CANCEL 시도
409ALREADY_RESPONDED이미 응답한 알림

report_statusstringXACCEPTED 등으로 필터
event_nonumberX특정 이벤트의 승계 이력만
page / sizenumberX기본 1 / 20
Response 200
{
  "items": [
    {
      "report_no": 3,
      "event_no": 12,
      "agency_no": 2,
      "agency_name": "종로소방서",
      "report_sequence": 1,
      "report_external_id": "R-20260808-0012",
      "report_trigger_reason": "NO_RESPONSE_TIMEOUT",
      "report_status": "ACCEPTED",
      "report_address": "서울시 종로구 세종대로 1",
      "report_distance_km": 1.234,
      "report_attempt_count": 1,
      "reported_at": "2026-08-08T14:33:10",
      "report_accepted_at": "2026-08-08T14:33:40"
